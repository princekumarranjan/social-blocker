# Wapas extension

1. Chrome > `chrome://extensions` > turn on **Developer mode**.
2. Click **Load unpacked** and choose this `wapas-extension` folder.
3. Click the Wapas icon (puzzle piece menu), set your limits and what you should be doing, press **Save**.

Counts reels on instagram.com/reels, YouTube Shorts and Facebook reels, plus minutes per site.
Works on desktop Chrome/Edge/Brave, and on Android in Kiwi Browser. It cannot count inside the Instagram or YouTube phone apps.
